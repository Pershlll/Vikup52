# Выкуп52

Мобильное PWA-приложение для оценки автомобилей под выкуп.

## Функции

- Ввод параметров авто: марка, модель, год, пробег, двигатель, коробка
- Учёт истории: количество владельцев, крашеных элементов
- Оценка по 5 критериям: кузов, техника, салон, юридическая чистота, ликвидность
- AI-анализ рыночной цены через веб-поиск
- Автоматический расчёт цены выкупа (от −20% до −40% от рынка)
- Вердикт: рекомендуется к покупке или нет (≥3 плюсов из 5)
- Расчёт потенциальной прибыли

## Установка на iPhone

1. Открыть Safari и перейти на сайт приложения
2. Нажать кнопку «Поделиться» → «На экран Домой»
3. Название: **Выкуп52** → Добавить
